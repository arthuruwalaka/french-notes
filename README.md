## Current focus

1. Use **me/m’** correctly as “me,” “to me,” or “myself.”
2. Distinguish **ce**, **ça**, **c’est**, and **sa**.
3. Practice **pouvoir**, **venir de**, **partir**, **comprendre**, and **dire**.
4. Form questions with **comment**, **quand**, **qui**, and **que**.

## How these notes are maintained

Only reusable grammar, essential expressions, conjugations, and recurring mistakes belong here. Ordinary vocabulary such as individual food or object nouns stays in Anki so these pages remain concise.
