# Corrections to remember

These came up in the first lessons. Review them before new exercises.

## Articles and gender

- un voiture → **une voiture**
- la ecole → **l’école**
- les ecole → **l’école** (singular) or **les écoles** (plural)
- deux chat → **deux chats**

## Être spelling

- sui → **suis**
- an → **est**
- somme → **sommes**
- ans / sant → **sont**
- etes → **êtes**

## Avoir spelling

- avon → **avons**
- je ai → **j’ai**

## Choosing the verb

- “I have a cat” = **J’ai un chat** (not *Je suis un chat*)
- “They are at school” = **Elles sont à l’école** (location uses **être**)
- “You are here” = **Vous êtes ici** (not *Vous avez*)
- “They have two cats” = **Ils ont deux chats** (not *Vous avez*)

## Accents and extra letters

- pret → **prêt** (feminine: **prête**)
- a l'ecole → **à l’école**
- etudiants → **étudiants**
- heuresuses → **heureuses**
