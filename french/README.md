# French TCF Canada prep

Starting from zero. Goal: **NCLC 7** for Canadian permanent residence.

This folder is a durable copy of the lessons so far. Keep using the Cursor chat for new exercises; use these notes to review.

## Current level

Beginner. Covered so far:

- Articles: `le`, `la`, `l’`, `les`, `un`, `une`, `des`
- Noun gender (always learn the article with the noun)
- `être` (to be)
- `avoir` (to have)
- Liaison (linking sounds)

## How we practice

- Exercises come **without answers**
- Reply first, then get corrections
- Blanks are written so they do not hide contractions (`J’ai`, not `Je ___`)

## Anki

Use one deck only: [French CEFR A1 Vocabulary – 1173 Words with Audio](https://ankiweb.net/shared/info/1834184398)

- 10 new cards per day
- Review first, then new cards
- Max 30 minutes
- Do **not** import deck presets or learning progress
- Say the French answer aloud

## Eight-week focus

| Weeks | Target |
| --- | --- |
| 1–2 | Survival French: pronunciation, present tense, high-frequency verbs, 700–900 words |
| 3–4 | A2: passé composé, futur proche, short messages, TCF task formats |
| 5–6 | B1 push: opinions, timed speaking/writing, full listening/reading sections |
| 7–8 | Exam mode: mocks, weakest-skill drills, tutor speaking |

NCLC 7 score targets:

- Listening: 458–502
- Reading: 453–498
- Speaking: 10–11/20
- Writing: 10–11/20

Book the exam only after mock scores are consistently in range.
